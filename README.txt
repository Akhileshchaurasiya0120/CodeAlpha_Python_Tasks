# Hangman Game Project
This is a text-based Hangman Game built using Python as part of the internship task.

## Features
- Random word selection using Python's 'random' module.
- Real-time display of hidden word letters and remaining lives.
- Input validation to check for invalid entries or duplicate guesses.

## Technologies Used
- Core Python 3
- Control flow structures (while loops, if-else statements)
- Data structures (lists, strings)

## How to Run
1. Open the 'hangman.py' file in any Python IDE or Terminal.
2. Press F5 or run 'python hangman.py' to play.

# Chatbot Project
This is a simple rule-based Chatbot built using Python as part of the internship task.

## Features
- Predefined rules for matching user inputs like greetings and standard questions.
- Case-insensitive matching and text cleaning using string methods (`.lower()` and `.strip()`).
- Continuous conversation loop until the user types an exit command.
- Exception handling to safely terminate the program with a custom goodbye message.

## Technologies Used
- Core Python 3
- Control flow structures (while loops, if-elif-else statements)
- Error and Exception Handling (try-except blocks)
- Built-in string and system modules

## How to Run
1. Open the 'chatbot.py' file in any Python IDE, IDLE, or Terminal.
2. Press F5 or run 'python chatbot.py' to talk with the chatbot.
3. Type 'exit' or 'bye' to quit the application.
